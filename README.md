# GlutenScout Prototype

This project implements a three-screen interactive mockup for the GlutenScout concept described in the brief.

## Included screens

1. Search / Nearby Results
2. Restaurant Detail / Verified Breakdown
3. Safe Picks / What to Order

## Run locally

From this folder, run:

```bash
python -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

## Design direction

- Pine, parchment, amber, rust, and moss palette derived from the brief
- Serif headline + sans body pairing
- Consistent verified-badge treatment across all screens
- Mobile-first layout with left-aligned composition
